# Bucket — это уровень критичности, а не отдельная сущность

Бакеты не хранятся отдельной таблицей: инцидент всегда принадлежит одному из четырёх
уровней A1–A4, а бакет — это срез инцидентов по текущему `level`. UI показывает ровно
четыре бакета. Это упрощает модель данных и исключает риск рассинхрона между
«бакетом» и «уровнем» как самостоятельными понятиями.
