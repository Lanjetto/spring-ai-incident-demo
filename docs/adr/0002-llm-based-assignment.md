# Отнесение сообщения к инциденту — решение LLM, а не эмбеддинг-поиск

Классификация критичности и отнесение сообщения к инциденту выполняются LLM
(Qwen3-32B) с промптами `classify.st` / `assign.st`, а не через сравнение эмбеддингов.
Причина: для недетерминированных пользовательских формулировок LLM точнее понимает
смысловую близость, чем числовой порог косинусной близости, и не требует подбора
порога срабатывания. pgvector используется только для RAG-подсказок по историческим
инцидентам. Нераспознанный ответ классификатора трактуется как A4.
