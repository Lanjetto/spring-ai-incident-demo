# Асинхронная обработка сообщений через Kafka

HTTP-приём (`POST /api/messages`) только публикует событие в Kafka и возвращает 202;
классификация и отнесение выполняются консьюмером асинхронно. Синхронный вариант
отвергнут: LLM-вызовы занимают секунды, и пользовательский запрос не должен на них
зависеть. Kafka даёт буферизацию и возможность повторной обработки упавших событий.
