# Эскалация на уровне инцидента по числу сообщений

Критичность инцидента растёт к A1 (FATAL) по мере накопления сообщений: каждые
`escalation-step-messages` (по умолчанию 10) сообщений поднимают уровень на одну
ступень. Эскалация на уровне бакета была отвергнута — она смешивает разные проблемы.
Начальный уровень ставит LLM по первому сообщению; эскалация только повышает
критичность, никогда не понижает.
